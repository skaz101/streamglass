# StreamGlass Android 0.8.1

The shared featured carousel keeps outgoing artwork visible beneath the incoming fade and prepares title logos with each scene. Artwork removal follows actual animation completion. Touch gestures, stable Play/My List controls, reduced motion, and existing phone layouts remain supported.

Native player behavior is unchanged. Version code 801 and version name 0.8.1 use the existing package ID and preview signing certificate, allowing an update over the previous installation. See the GitHub release for automated validation and installers; physical-phone smoothness has not been measured in this update.
