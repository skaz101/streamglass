# StreamGlass Android 0.6.2 preview

- Classic, Amethyst purple and OLED browsing themes, applied immediately and saved locally.
- Appearance controls replace the StreamGlass settings button.
- Stremio email and avatar appear in the profile menu, with an initial fallback.
- Profile refresh uses the signed-in session at startup and account sync.
- Main-tab transitions and a moving active-tab indicator.
- A cleaner search bar, clear button and responsive poster-grid results.
- Featured titles now say MOVIE or SERIES instead of S FILM.

Install over the existing preview; the package and signing certificate are unchanged.
Physical-phone testing remains necessary. LG stays on 0.4.0.
