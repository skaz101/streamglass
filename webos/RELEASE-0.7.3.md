# StreamGlass TV 0.7.3

This release accompanies the Android navigation and action-layout improvements.
Shared React screens retain the TV layout and remote controls; library queries
now keep each core request paired with its snapshot. Saving a title invalidates
cached recommendations so returning to For You includes the updated library.

Install over `com.streamglass.tv` to retain state. See [installation](INSTALL.md),
[shared release notes](../android/RELEASE-0.7.3.md) and [release audit](../RELEASE-AUDIT.md).
