# StreamGlass TV 0.7.2

Top movies and Top series now lead Home. The shared default palette returns to
neutral black and charcoal, with refined carousel motion. The Android host adds
artwork-derived ambient blur and revised phone spacing/controls.

Install over `com.streamglass.tv` to retain state. See [installation](INSTALL.md),
[shared release notes](../android/RELEASE-0.7.2.md) and [release audit](../RELEASE-AUDIT.md).
