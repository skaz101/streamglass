# StreamGlass TV 0.7.1

Curated Featured, seasonal, Netflix, HBO Max, Anime and Top collections now
fill Home by default. Settings can switch back to addon catalogs. The shared
React carousel has an animated countdown and decoded artwork crossfades, with
updated colors and glass controls. Remote navigation and reduced motion remain.

Install the IPK over `com.streamglass.tv` to retain local state. See
[installation instructions](INSTALL.md), [shared release notes](../android/RELEASE-0.7.1.md)
and the [release audit](../RELEASE-AUDIT.md).
