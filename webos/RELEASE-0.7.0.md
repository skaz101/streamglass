# StreamGlass TV 0.7.0

The LG webOS package includes the shared React interface, cinematic home carousel,
restyled browsing screens and release calendar. Install the IPK over the existing
`com.streamglass.tv` app to retain local state.

See [installation instructions](INSTALL.md), [shared release notes](../android/RELEASE-0.7.0.md)
and the [release audit](../RELEASE-AUDIT.md) for validation and limitations.
